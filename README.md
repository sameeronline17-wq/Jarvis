# JARVIS V1

Grundversion: futuristisches Interface + sicheres Backend + OpenAI.

Wichtig:
- API-Keys gehören ausschließlich in `.env`.
- `.env` darf niemals veröffentlicht oder in Git eingecheckt werden.
- ElevenLabs ist vorbereitet, aber noch nicht angeschlossen.
- Spracheingabe, Websuche und Integrationen kommen später.

Start:
1. `npm install`
2. `.env.example` zu `.env` kopieren
3. OpenAI-Key in `.env` eintragen
4. `npm start`
